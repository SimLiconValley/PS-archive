# 활용 방법

## 1. 컴파일

컴파일러는 하기 기술한 방법 중 1개를 선택

1. Programmers 같은 경우 **웹IDE 자체**에 solution 함수가 있습니다. 

    > 이걸 그냥 직접 수정해서 하는게 실력향상에 도움이 될 수 있습니다.



2. **웹 컴파일러**

    |서비스명|링크|언어|
    |---|---|---|
    |My Compiler  | [my compiler](https://www.mycompiler.io/de/new/cpp) |all|
    |Compiler Explorer | [compiler explorer](https://godbolt.org/) |all|


3. 로컬 디바이스에서 설정한 컴파일러 (이 경우 환경값 업로드해주면 감사)
    > 환경값은 최상단 경로에 자유로운 방법(txt,md 등)으로 업로드 하거나 이슈에 올리기

4. 3과 같은 방법의 **Docker 이미지**
    > 구체적인 계획 없음

## 2. 업로드

```
|   barkingdog_0x00_1.cpp
|   README.md
|
+---.github
|   +---ISSUE_TEMPLATE
|   |       bug_report.md
|   |       config.yml
|   |       custom.md
|   |       feature_request.md
|   |
|   \---workflows
|           deadline-checker.yml
|
+---0_docs
|       01_활용방법.md
|
+---1_Baekjoon
|       백준 바로가기.url
|
\---2_Programmers
    |   프로그래머스 바로가기.url
    |
    \---159994 카드뭉치
            simjeehoon.cpp
```

- 코딩테스트 사이트의 디렉토리명은 `n_코딩테스트사이트명` 으로 작성

- 코드는 디렉토리 내부에 
  - `문제번호` 와 같은 문제를 고유식별할 수 있는 이름으로 디렉토리 생성
  - 해당 디렉토리 내부에 `본인ID.확장자` 와 같이 작성 (ex. `simjeehoon.cpp`)

- solution 함수만 업로드 해도 됨
  - main flow는 추후 논의

- 소스코드 파일을 추가/수정 방법
  - **개인 브랜치**로 checkout 하여 작업 합니다.
